# Pemrograman_DhiyaDzakiraAnnuha_Vanadium_TLS2026

Nama: Dhiya Dzakira Annuha\
Kelompok: Vanadium
### Isi Repository
Repo berisi satu file PDF dan dua file .cpp yang dibuat sebagai penyelesaian tugas **Luminous Quest: Pemrograman Dasar** TLS 2026. FIle PDF dengan nama "File_1.pdf" berisi hasil penyelesaian fase 1 berupa satu _pseudocode_, satu _flowchart_, dan penjelasan logika untuk masing-masing darinya. **Problem 1** diselesaikan menggunakan _pseudocode_ dan **Problem 2** diselesaikan dengan _flowchart_. Dua file .cpp merupakan penyelesaian fase 2, dengan file "Problem_1.cpp" merupakan penyelesaian untuk **Problem 1** dan "Problem_2.cpp" merupakan penyelesaan **Problem 2**.
